# SEO инструментите

Четири скрипта, всеки с една задача. Пускат се в този ред.

```bash
python3 scripts/seo/health.py              # живият сайт наред ли е
npm run build && python3 scripts/seo/audit.py   # кодът наред ли е
python3 scripts/seo/decay.py               # какво трябва да се разчисти
python3 scripts/seo/rank.py                # мърдаме ли по заявките
python3 scripts/seo/compare.py             # какво правят конкурентите
```

| Скрипт | Какво прави | Излиза с 1 при |
|---|---|---|
| `health.py` | Проверява всеки адрес на живо, каноничните, robots.txt и www | първия недостъпен адрес |
| `audit.py` | Пълен одит върху билда — заглавия, канонични, H1, обем, sitemap, връзки, структурирани данни | КРИТИЧНО или високо |
| `decay.py` | Канибализация, остаряло, тънко, сираци и задънени улици | КРИТИЧНО или високо |
| `rank.py` | Позициите по 14 целеви заявки; води история в `rank-history.json` | никога (данните са ориентир) |
| `compare.py` | Сравнение с 14 български конкурента | никога |

## Защо всеки от тях съществува

**`health.py`** — на 27.08.2026 `/demo` върна 404 на живо, защото един клон
преименува `app/demo/page.tsx`, без да остави страница на маршрута. Билдът мина
чисто, нищо не изгърмя, адресът просто изчезна. Този скрипт хваща точно това.

**`audit.py`** — намери, че каноничният адрес в коренния layout сочи към „/“,
тоест всяка страница без свой canonical се обявяваше за копие на началната.
Това беше причината сайтът да съществува за Google като една-единствена страница.

**`rank.py`** — през DuckDuckGo, не през Google: Google връща CAPTCHA на
автоматични заявки. Числата са ориентир за посоката. Точните позиции идват от
Search Console, щом бъде свързан.

**`decay.py`** — отговорът на въпроса „не трябва ли да се разчиства, а не само
да се трупа". Google има отделна система за това: сайт с голям дял безполезни
страници се сваля ЦЯЛ, не само слабите страници. Десет забравени текста могат
да свалят десетте добри. Скриптът НЕ трие нищо — само показва и предлага,
защото „слаба страница" и „страница, която още не е получила шанс" си приличат
отвън.

**`compare.py`** — конкурентите не печелят с техника, а с брой отговорени
въпроси. Скриптът мери разликата: страници, обем и структурирани данни.
